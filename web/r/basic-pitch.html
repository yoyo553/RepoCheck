使い方のルート（上ほどおすすめ）

🐳 Docker で動かすおすすめ

環境ごと再現できるので、実は手作業のインストールより失敗が少ない方法です。Docker Desktop（無料）を先に入れてください。

git clone https://github.com/spotify/basic-pitch.git
cd basic-pitch
docker compose up

🐍 Python で動かす

仮想環境（venv）を作ってから必要なライブラリを入れます。venv を作らずに入れるとパソコン全体のPython環境が壊れるので必ず作ってください。

git clone https://github.com/spotify/basic-pitch.git
cd basic-pitch
python3 -m venv venv
source venv/bin/activate
pip install -r . # pyproject.toml があるので pip install . 

# 終わったら（仮想環境を抜ける）
# deactivate

※ コマンドは「ターミナル」アプリに貼り付けて Enter で実行します。1行ずつ実行してください。

注意点・つまずきポイント

  • READMEに Python 3.11 の記載があります。手元のバージョンが違うと失敗しやすいので合わせてください（確認：python3 --version）。
  • エラーが出たら、エラー文をコピーして このリポジトリのIssues 内で検索してください。同じ問題の人がほぼ必ずいます。
